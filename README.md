# Trading Course Bot
هسته آماده ربات آموزشی رایگان ترید با aiogram 3.

منوی اصلی برای همه:
🎓 شروع یادگیری
💬 پشتیبانی

برای ادمین:
👑 پنل مدیریت

دیتابیس SQLite است و برای نصب سریع روی VPS مناسب است. ساختار جداول آزمون، تایمر، cooldown، پیشرفت، کانال اجباری، پیام‌ها و لاگ‌ها هم از ابتدا در دیتابیس آماده شده است.
