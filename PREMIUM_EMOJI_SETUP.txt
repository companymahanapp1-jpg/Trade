PREMIUM CUSTOM EMOJI CONFIGURATION
===================================

The bot uses the exact IDs supplied by the client:

START LEARNING: 5935946026308342844
SUPPORT:        5938359183748370657
ADMIN PANEL:    5935933089866846598
CHAPTER BUTTONS:5938069973535559743

They are NOT printed as text. They are passed directly to:
KeyboardButton(icon_custom_emoji_id=...)

The bot uses ReplyKeyboardMarkup only. No InlineKeyboardMarkup is used.

IMPORTANT:
The Telegram account that owns the bot must be eligible to use custom emoji.
If Telegram still renders a normal icon/text after deployment, the next diagnostic
step is to inspect the actual Telegram API response/error from sending a test button.
Do not replace the IDs with emoji characters.
