# Trading Course Bot V3
- aiogram 3.22.0
- Inline buttons use Telegram Bot API 9.4+ `style` and `icon_custom_emoji_id`.
- Real custom emoji IDs must be supplied in Service Variables.

Install:
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python main.py
```
On Rivaly, set BOT_TOKEN and OWNER_ID as Service Variables.
